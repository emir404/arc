# Stream C — New and larger Turkish venture funds and the institutional capital landscape (2024–2026)

Compiled 2026-09-18 for the IB Business Management EE: "To what extent does the increasing concentration of venture capital funding in Türkiye influence the scalability and survival rates of early-stage startups?"

## READ FIRST — how this file was verified, and what it could not do

1. **Page fetches were impossible.** The organisation's egress proxy returned `403` on CONNECT for every non-GitHub domain tested (revo.vc, ifc.org, disclosures.ifc.org, ebrd.com, eif.org, spk.gov.tr, tspb.org.tr, tubitak.gov.tr, kap.org.tr, startinturkiye.gov.tr, webrazzi.com, egirisim.com, mobidictum.com, vestbee.com, pitchbook.com, dealroom.co, techcrunch.com, sifted.eu, wikipedia.org, web.archive.org, archive.ph, r.jina.ai, google/bing/duckduckgo…). Therefore **no figure below was confirmed by reading the source page.**
2. **Verification was by search-result excerpts only.** Each fact is tagged with the *kind* of excerpt that carries it:
   - `TITLE` = the figure appears in the verbatim title of a result URL (strongest excerpt evidence available here);
   - `SUMMARY` = the figure appears only in the search tool's synthesised summary of the results (weaker; treat as a lead);
   - `DATASET-ROW` = a verbatim CSV row from the IFC/World Bank open-data file `finances.worldbank.org` (IFC Investment Services Projects, snapshot dated 2022-09-02) mirrored in the public GitHub repository `tsegall/semantic-types` (paths `data/opendata_socrata_com/finances.worldbank.org/{93bt-dkup,niaa-ju4z,eqr4-mx5u,j646-ma4b,3dmc-prbs}.csv`) and the older DataCamp copy in `Zahedasghar/data_analytics/investment_services_projects.csv`. These rows are IFC's own disclosure data (project number, date disclosed, board date, "IFC investment for Equity (Million USD)", "Total IFC investment as approved by Board (Million USD)");
   - `TERTIARY` = text found inside third-party GitHub files (AI-generated investor notes, scraped news feeds, conference bios). Leads only.
3. **Grades**: `verified by 2+ independent excerpts` / `single-source excerpt` / `NOT VERIFIED`.
4. **The session's WebSearch budget (200 calls, shared across all agents) was exhausted after this stream's 19th query.** The coordinator's follow-up instruction to re-verify everything with domain-restricted searches (`allowed_domains`) could therefore **not** be executed. Items marked *NOT SEARCHED* were never queried. A ready-to-run query list is at the end of this file.
5. Fund-size vocabulary used throughout: **TARGET** (announced goal) ≠ **FIRST CLOSE** (capital legally committed at first closing) ≠ **FINAL CLOSE** (total committed at last closing) ≠ **DEPLOYED** (actually invested). No target is presented as money raised.
